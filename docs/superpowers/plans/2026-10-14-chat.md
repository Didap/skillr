# Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A persistent, realtime 1:1 chat between the company and the professional of every mutual match, living inside the existing "Match" section.

**Architecture:** A mutual `matches` row is the conversation. Messages live in a new `chat_messages` table; read markers, last activity and block state are new columns on `matches`; reports go to `chat_reports`. Server actions in `src/app/actions/chat.ts` are the only write path and the DB is the source of truth; after each write they publish to Pusher private channels (`private-match-{id}`, `private-user-{id}`) authorized by `/api/pusher/auth`. The client merges server pages, Pusher events and optimistic sends, and falls back to polling when Pusher is missing or down.

**Tech Stack:** Next 16.2.4 (App Router, server actions), React 19, drizzle-orm 0.45 + postgres-js, next-auth v5, Pusher Channels (`pusher` / `pusher-js`), Cloudinary, Resend, zod 4, Tailwind v4, framer-motion, sonner, Vitest (new).

**Spec:** `docs/superpowers/specs/2026-10-14-chat-design.md`

## Global Constraints

- `AGENTS.md`: this Next.js has breaking changes. Before using any Next API you have not used in this repo yet, read the matching guide in `node_modules/next/dist/docs/` (route handlers: `01-app/01-getting-started/15-route-handlers.md`). The middleware file is `src/proxy.ts`; its matcher already skips `/api`.
- Server actions return `{ success: true, data } | { error: string }`; user-facing strings are Italian, informal "tu" (see `DESIGN.md` → Voice).
- A `"use server"` file may export **only async functions** (type exports are fine, constants are not).
- IDs are `text` with `$defaultFn(() => crypto.randomUUID())`.
- Message body: trimmed, 1–2000 characters, or null when an attachment is present.
- Attachments: `image/jpeg`, `image/png`, `image/webp`, `image/gif`, `application/pdf`; max 5 MB (5 * 1024 * 1024 bytes). Cloudinary folder `helllo/chat/{matchId}`, `type: "authenticated"`, `resource_type: "image"`, signed delivery URLs.
- Page size 50 messages; `after` catch-up returns at most 200.
- Rate limit: more than 20 messages by one sender in the last 10 seconds → `"Stai inviando troppi messaggi. Riprova tra qualche secondo."`
- Typing: client event at most once every 3 s; indicator hides 5 s after the last event. Thread polling fallback every 10 s while visible; unread badge fallback every 60 s.
- Channels: `private-match-{matchId}`, `private-user-{userId}`. Events: `message:new`, `message:read`, `conversation:blocked`, `conversation:unblocked`, `inbox:update`, client event `client-typing`.
- Only mutual matches (`professional_status = 'liked' and company_status = 'liked'`) have a chat.
- Schema changes are applied with `npm run db:push`; do not add files under `src/db/migrations`.
- Colours and type only from the existing Helllo tokens (`bg-viola`, `bg-crema`, `bg-rosa`, `bg-rosso`, `text-viola-500`, …). No new colours.
- New env vars: `CHAT_MODERATION_EMAIL` (app), `TEST_DATABASE_URL` (tests, optional; default `postgres://postgres:password@localhost:5434/helllo_test`).
- Commits: conventional (`feat(chat): …`, `test(chat): …`), each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Whitespace-only message** ("   ", "\n\n") must be rejected as empty, not stored as an empty bubble → pinned in Task 6 (`rejects empty and whitespace-only messages`).
2. **Messages sent between the server render and the Pusher subscription** must still appear: the thread catches up with `getMessages({ after })` on `pusher:subscription_succeeded` → server side pinned in Task 6 (`after returns only newer messages`), merge pinned in Task 12 (`dedupes by id`).
3. **A cursor id from another conversation** must not leak or page through someone else's messages → pinned in Task 6 (`ignores a cursor from another match`).
4. **Block racing a send** (block lands between the access check and the insert) must not store the message → the insert runs in a transaction guarded by `blocked_by_id is null`; pinned in Task 6 (`rejects sends on a blocked conversation and stores nothing`).
5. **Own messages never count as unread**, including from a second tab of the same user → pinned in Task 7 (`counts only the other side's messages`).

```ts
import { execSync } from "node:child_process";
import postgres from "postgres";
import { TEST_DATABASE_URL } from "./test-db-url";

/**
 * Recreates the test database from scratch and pushes the current schema into it.
 * Refuses to touch anything whose name doesn't end in "_test".
 */
export default async function setup() {
  const url = new URL(TEST_DATABASE_URL);
  const dbName = url.pathname.slice(1);
  if (!dbName.endsWith("_test")) {
    throw new Error(`Refusing to run tests against "${dbName}": the test database name must end in _test`);
  }

  const adminUrl = new URL(TEST_DATABASE_URL);
  adminUrl.pathname = "/postgres";
  const admin = postgres(adminUrl.toString(), { max: 1, onnotice: () => {} });
  try {
    await admin.unsafe(`drop database if exists "${dbName}" with (force)`);
    await admin.unsafe(`create database "${dbName}"`);
    // Timestamps are "timestamp without time zone"; drizzle reads them as UTC
    await admin.unsafe(`alter database "${dbName}" set timezone to 'UTC'`);
  } finally {
    await admin.end();
  }

  // drizzle.config.ts loads .env.local with dotenv, which never overrides a variable
  // that is already set, so DATABASE_URL here wins.
  execSync("npx drizzle-kit push --force", {
    stdio: "inherit",
    env: { ...process.env, DATABASE_URL: TEST_DATABASE_URL },
  });
}
```

```ts
import { sql } from "drizzle-orm";
import { db } from "@/db";
import { chatMessages, companyProfiles, matches, professionalProfiles, users } from "@/db/schema";

export type TestUser = { id: string; role: "professional" | "company" };

export async function resetDb() {
  await db.execute(sql`truncate table "user" cascade`);
}

async function createUser(role: TestUser["role"], name: string): Promise<TestUser> {
  const [user] = await db
    .insert(users)
    .values({ email: `${crypto.randomUUID()}@test.local`, role, name })
    .returning({ id: users.id });
  if (role === "company") {
    await db.insert(companyProfiles).values({ userId: user.id, companyName: name });
  } else {
    const [firstName, lastName = ""] = name.split(" ");
    await db.insert(professionalProfiles).values({ userId: user.id, firstName, lastName, title: "Designer" });
  }
  return { id: user.id, role };
}

export const createCompany = (name = "Acme Srl") => createUser("company", name);
export const createProfessional = (name = "Luca Rossi") => createUser("professional", name);
export const createStranger = () => createUser("professional", "Marta Bianchi");

/** A swipe match between a company and a professional, mutual unless told otherwise. */
export async function seedMatch(opts: { mutual?: boolean; company?: TestUser; pro?: TestUser; matchedAt?: Date } = {}) {
  const company = opts.company ?? (await createCompany());
  const pro = opts.pro ?? (await createProfessional());
  const mutual = opts.mutual ?? true;
  const [match] = await db
    .insert(matches)
    .values({
      professionalId: pro.id,
      companyId: company.id,
      professionalStatus: "liked",
      companyStatus: mutual ? "liked" : "pending",
      matchedAt: mutual ? (opts.matchedAt ?? new Date()) : null,
    })
    .returning();
  return { company, pro, match };
}

export async function insertMessage(matchId: string, senderId: string, body: string, createdAt?: Date) {
  const [message] = await db
    .insert(chatMessages)
    .values({ matchId, senderId, body, ...(createdAt ? { createdAt } : {}) })
    .returning();
  return message;
}
```

```ts
// Named chat_messages: an old initial migration created a differently shaped "messages"
// table that may still exist in some databases.
export const chatMessages = pgTable("chat_messages", {
  id: text("id").primaryKey().$defaultFn(() => crypto.randomUUID()),
  matchId: text("match_id").notNull().references(() => matches.id, { onDelete: "cascade" }),
  senderId: text("sender_id").notNull().references(() => users.id, { onDelete: "cascade" }),
  body: text("body"),
  attachmentPublicId: text("attachment_public_id"),
  attachmentName: text("attachment_name"),
  attachmentMime: text("attachment_mime"),
  attachmentSize: integer("attachment_size"),
  createdAt: timestamp("created_at").notNull().defaultNow(),
}, (t) => [
  // Threads are read newest first by match
  index("chat_messages_match_created_idx").on(t.matchId, t.createdAt),
  // The rate limit counts a sender's recent messages
  index("chat_messages_sender_created_idx").on(t.senderId, t.createdAt),
  check("chat_messages_content_check", sql`${t.body} is not null or ${t.attachmentPublicId} is not null`),
]);

export const chatReports = pgTable("chat_reports", {
  id: text("id").primaryKey().$defaultFn(() => crypto.randomUUID()),

  messageId: text("message_id").references(() => chatMessages.id, { onDelete: "set null" }),
  reason: chatReportReasonEnum("reason").notNull(),
  details: text("details"),
  createdAt: timestamp("created_at").defaultNow(),
```

```ts
import { eq } from "drizzle-orm";
import { db } from "@/db";
import { matches } from "@/db/schema";

export type Side = "professional" | "company";
type MatchRow = typeof matches.$inferSelect;
export type Conversation = { match: MatchRow; side: Side; otherUserId: string };

/**
 * The one access rule for the chat: the viewer is one of the two sides of a mutual match.
 * Every chat action and the Pusher channel authorization go through here.
 */
export async function loadConversation(matchId: string, userId: string): Promise<Conversation | { error: string }> {
  const match = await db.query.matches.findFirst({ where: eq(matches.id, matchId) });
  if (!match) return { error: "Conversazione non trovata" };

  const side: Side | null =
    match.professionalId === userId ? "professional" : match.companyId === userId ? "company" : null;
  if (!side) return { error: "Non autorizzato" };

  if (match.professionalStatus !== "liked" || match.companyStatus !== "liked") {
    return { error: "Conversazione non disponibile" };
  }

  return { match, side, otherUserId: side === "professional" ? match.companyId : match.professionalId };
}

/** The read marker of one side of the conversation. */
export function readMarkerOf(match: MatchRow, side: Side) {
  return side === "professional" ? match.professionalLastReadAt : match.companyLastReadAt;
}
```

```ts
import Pusher from "pusher";

let client: Pusher | null | undefined;

/** Server SDK, or null when the Pusher env vars are missing (the chat then polls). */
export function getPusher(): Pusher | null {
  if (client !== undefined) return client;
  const appId = process.env.PUSHER_APP_ID;
  const key = process.env.NEXT_PUBLIC_PUSHER_KEY;
  const secret = process.env.PUSHER_SECRET;
  const cluster = process.env.NEXT_PUBLIC_PUSHER_CLUSTER;
  client = appId && key && secret && cluster ? new Pusher({ appId, key, secret, cluster, useTLS: true }) : null;
  return client;
}

/**
 * Notifies subscribers after a DB write. The write is the source of truth, so a Pusher
 * outage is logged and never fails the caller. `socketId` skips the sender's own tab.
 */
export async function publish(channels: string | string[], event: string, data: unknown, socketId?: string) {
  const pusher = getPusher();
  if (!pusher) return;
  try {
    await pusher.trigger(channels, event, data, socketId ? { socket_id: socketId } : undefined);
  } catch (error) {
    console.error(`Pusher trigger failed (${event}):`, error);
  }
}
```

```ts
// Pusher socket ids look like "123.456"; anything else is dropped, not an error
const socketIdSchema = z.string().regex(/^\d+\.\d+$/).optional().catch(undefined);

class ConversationClosed extends Error {}

/** The signed-in user and their conversation, or the error to return. */
async function viewerConversation(matchId: string) {
  const user = await requireUser();
  if ("error" in user) return { error: user.error };
  const convo = await loadConversation(matchId, user.id);
  if ("error" in convo) return { error: convo.error };
  return { user, convo };
}

const cursorSchema = z
  .object({ before: z.string().min(1).optional(), after: z.string().min(1).optional() })
  .refine((c) => !(c.before && c.after));

/**
 * A page of the thread, oldest first. Without a cursor: the latest PAGE_SIZE messages.
 * `before`: older ones (scrolling up). `after`: newer ones (catching up after a reconnect).
 * Cursors are message ids compared as (created_at, id) in SQL, so JS millisecond rounding
 * never skips or repeats a message; a cursor from another match matches nothing.
 */
export async function getMessages(matchId: string, cursor: { before?: string; after?: string } = {}) {
  const ctx = await viewerConversation(matchId);
  if ("error" in ctx) return { error: ctx.error };
  const parsed = cursorSchema.safeParse(cursor);
  if (!parsed.success) return { error: "Richiesta non valida" };
  const { before, after } = parsed.data;

  try {
    const pivot = (id: string) =>
      sql`(select c.created_at, c.id from chat_messages c where c.id = ${id} and c.match_id = ${matchId})`;
    const where = and(
      eq(chatMessages.matchId, matchId),
      before ? sql`(${chatMessages.createdAt}, ${chatMessages.id}) < ${pivot(before)}` : undefined,
      after ? sql`(${chatMessages.createdAt}, ${chatMessages.id}) > ${pivot(after)}` : undefined
    );

    const rows = after
      ? await db.select().from(chatMessages).where(where)
          .orderBy(asc(chatMessages.createdAt), asc(chatMessages.id)).limit(AFTER_LIMIT)
      : await db.select().from(chatMessages).where(where)
          .orderBy(desc(chatMessages.createdAt), desc(chatMessages.id)).limit(PAGE_SIZE + 1);

    const hasMore = !after && rows.length > PAGE_SIZE;
    const page = after ? rows : rows.slice(0, PAGE_SIZE).reverse();
    const { match, side } = ctx.convo;
    const otherLastReadAt = readMarkerOf(match, side === "professional" ? "company" : "professional");

    const data: ThreadPage = {
      messages: page.map(toChatMessage),
      hasMore,
      otherLastReadAt: otherLastReadAt?.toISOString() ?? null,
      blockedById: match.blockedById,
    };
    return { success: true as const, data };
  } catch (error) {
    console.error("Error loading chat messages:", error);
    return { error: "Errore durante il caricamento dei messaggi" };
  }
}

const sendSchema = z.object({
  clientId: z.string().min(1).max(64),
  body: z.string().trim().max(MAX_BODY_LENGTH, `Massimo ${MAX_BODY_LENGTH} caratteri`).optional(),
  attachment: z
    .object({
      publicId: z.string().min(1).max(300),
      name: z.string().trim().min(1).max(200),
      mime: z.enum(ATTACHMENT_MIME_TYPES),
      size: z.number().int().positive().max(MAX_ATTACHMENT_BYTES),
    })
    .optional(),
  socketId: socketIdSchema,
});

export async function sendMessage(matchId: string, input: SendMessageInput) {
  const ctx = await viewerConversation(matchId);
  if ("error" in ctx) return { error: ctx.error };
  const parsed = sendSchema.safeParse(input);
  if (!parsed.success) return { error: parsed.error.issues[0]?.message ?? "Messaggio non valido" };

  const { clientId, attachment, socketId } = parsed.data;
  const body = parsed.data.body || null;
  if (!body && !attachment) return { error: "Il messaggio è vuoto" };
  if (attachment && !isInMatchFolder(attachment.publicId, matchId)) return { error: "Allegato non valido" };

  const { user, convo } = ctx;
  if (convo.match.blockedById) return { error: "Questa conversazione è chiusa" };

  try {
    const [{ recent }] = await db
      .select({ recent: count() })
      .from(chatMessages)
      .where(and(eq(chatMessages.senderId, user.id), sql`${chatMessages.createdAt} > now() - interval '10 seconds'`));
    if (recent >= 20) return { error: "Stai inviando troppi messaggi. Riprova tra qualche secondo." };

    const row = await db.transaction(async (tx) => {
      const [inserted] = await tx
        .insert(chatMessages)
        .values({
          matchId,
          senderId: user.id,
          body,
          attachmentPublicId: attachment?.publicId ?? null,
          attachmentName: attachment?.name ?? null,
          attachmentMime: attachment?.mime ?? null,
          attachmentSize: attachment?.size ?? null,
        })
        .returning();
      // now() is the transaction's start time, the same instant as the message's created_at.
      // The guard on blocked_by_id makes a block that lands mid-send roll the insert back.
      const marker = convo.side === "professional" ? { professionalLastReadAt: sql`now()` } : { companyLastReadAt: sql`now()` };
      const updated = await tx
        .update(matches)
        .set({ lastMessageAt: sql`now()`, ...marker })
        .where(and(eq(matches.id, matchId), isNull(matches.blockedById)))
        .returning({ id: matches.id });
      if (updated.length === 0) throw new ConversationClosed();
      return inserted;
    });

    const message: ChatMessage = toChatMessage(row);
    await Promise.all([
      publish(matchChannel(matchId), CHAT_EVENTS.newMessage, message, socketId),
      publish([userChannel(convo.otherUserId), userChannel(user.id)], CHAT_EVENTS.inbox, { matchId }, socketId),
    ]);
    return { success: true as const, data: { message, clientId } };
  } catch (error) {
    if (error instanceof ConversationClosed) return { error: "Questa conversazione è chiusa" };
    console.error("Error sending chat message:", error);
    return { error: "Messaggio non inviato. Riprova." };
  }
}
```

```ts
import { sql } from "drizzle-orm";
import { db } from "@/db";
import type { ChatPreview } from "./types";

// A message is unread for `userId` when the other side sent it after userId's read marker.
const unreadFor = (userId: string) => sql`
  u.sender_id <> ${userId}
  and u.created_at > coalesce(
    case when m.professional_id = ${userId} then m.professional_last_read_at else m.company_last_read_at end,
    '-infinity'::timestamp
  )`;

/** Last message and unread count of each match, in one query. */
export async function loadChatPreviews(userId: string, matchIds: string[]): Promise<Map<string, ChatPreview>> {
  if (matchIds.length === 0) return new Map();
  const ids = sql.join(matchIds.map((id) => sql`${id}`), sql`, `);
  const rows = await db.execute<{
    match_id: string;
    last_body: string | null;
    last_has_attachment: boolean;
    last_sender_id: string | null;
    unread: number;
  }>(sql`
    select
      m.id as match_id,
      lm.body as last_body,
      lm.attachment_public_id is not null as last_has_attachment,
      lm.sender_id as last_sender_id,
      (select count(*)::int from chat_messages u where u.match_id = m.id and ${unreadFor(userId)}) as unread
    from matches m
    left join lateral (
      select c.body, c.attachment_public_id, c.sender_id
      from chat_messages c
      where c.match_id = m.id
      order by c.created_at desc, c.id desc
      limit 1
    ) lm on true
    where m.id in (${ids})
  `);

  return new Map(
    rows.map((r) => [
      r.match_id,
      {
        lastMessage: r.last_sender_id
          ? { body: r.last_body, hasAttachment: r.last_has_attachment, fromMe: r.last_sender_id === userId }
          : null,
        unread: r.unread,
      },
    ])
  );
}

/** Unread messages across the user's mutual matches (the nav badge). */
export async function unreadTotal(userId: string): Promise<number> {
  const [row] = await db.execute<{ total: number }>(sql`
    select count(*)::int as total
    from chat_messages u
    join matches m on m.id = u.match_id
    where (m.professional_id = ${userId} or m.company_id = ${userId})
      and m.professional_status = 'liked' and m.company_status = 'liked'
      and ${unreadFor(userId)}
  `);
  return row?.total ?? 0;
}
```

```ts
export async function markRead(matchId: string, socketId?: string) {
  const ctx = await viewerConversation(matchId);

    const [row] = await db
      .update(matches)
      .set(marker)
      .where(eq(matches.id, matchId))

    const readAt = (convo.side === "professional" ? row.professionalLastReadAt : row.companyLastReadAt)!.toISOString();

  }
}
```

```ts
    `Match: ${input.matchId}`,

    `Messaggio segnalato: ${input.reportedMessageId ?? "intera conversazione"}`,

  ];

    text,
    html: `<pre style="font-family:monospace;white-space:pre-wrap">${escapeHtml(text)}</pre>`,
```

```ts
  if (updated.length > 0) {
    await Promise.all([
      publish(matchChannel(matchId), CHAT_EVENTS.blocked, { blockedById: userId }),
      publish([userChannel(otherUserId), userChannel(userId)], CHAT_EVENTS.inbox, { matchId }),
    ]);
    return userId;
  }
  const [current] = await db.select({ blockedById: matches.blockedById }).from(matches).where(eq(matches.id, matchId));
  return current?.blockedById ?? userId;
}

export async function blockConversation(matchId: string) {
  const ctx = await viewerConversation(matchId);
  if ("error" in ctx) return { error: ctx.error };
  try {
    const blockedById = await applyBlock(matchId, ctx.user.id, ctx.convo.otherUserId);
    return { success: true as const, data: { blockedById } };
  } catch (error) {
    console.error("Error blocking conversation:", error);
    return { error: "Errore durante il blocco della conversazione" };
  }
}

export async function unblockConversation(matchId: string) {
  const ctx = await viewerConversation(matchId);
  if ("error" in ctx) return { error: ctx.error };
  const { user, convo } = ctx;
  if (convo.match.blockedById !== user.id) return { error: "Solo chi ha bloccato la conversazione può sbloccarla" };
  try {
    await db
      .update(matches)
      .set({ blockedById: null, blockedAt: null })
      .where(and(eq(matches.id, matchId), eq(matches.blockedById, user.id)));
    await Promise.all([
      publish(matchChannel(matchId), CHAT_EVENTS.unblocked, {}),
      publish([userChannel(convo.otherUserId), userChannel(user.id)], CHAT_EVENTS.inbox, { matchId }),
    ]);
    return { success: true as const, data: { blockedById: null } };
  } catch (error) {
    console.error("Error unblocking conversation:", error);
    return { error: "Errore durante lo sblocco della conversazione" };
  }
}
```

```ts
 * Step one of sending a file: upload it as a private ("authenticated") Cloudinary resource
 * in this conversation's folder. sendMessage then references it by public id.
 */
export async function uploadChatAttachment(matchId: string, formData: FormData) {
  const ctx = await viewerConversation(matchId);
  if ("error" in ctx) return { error: ctx.error };
  if (ctx.convo.match.blockedById) return { error: "Questa conversazione è chiusa" };

  const file = formData.get("file");
  if (!(file instanceof File)) return { error: "File mancante" };
  if (!(ATTACHMENT_MIME_TYPES as readonly string[]).includes(file.type)) {
    return { error: "Formato non supportato. Invia un'immagine (JPG, PNG, WebP, GIF) o un PDF." };
  }
  if (file.size > MAX_ATTACHMENT_BYTES) return { error: "File troppo grande. Massimo 5MB." };

  try {
    const buffer = Buffer.from(await file.arrayBuffer());
    const result = await new Promise<{ public_id: string }>((resolve, reject) => {
      cloudinary.uploader
        .upload_stream(
          // PDFs are "image" resources in Cloudinary too, so one resource type covers both
          { folder: chatFolder(matchId), type: "authenticated", resource_type: "image" },
          (error, res) => (error || !res ? reject(error ?? new Error("Empty Cloudinary response")) : resolve(res))
        )
        .end(buffer);
    });
    const data: UploadedAttachment = {
      publicId: result.public_id,
      name: file.name.slice(0, 200) || "allegato",
      mime: file.type as AttachmentMime,
      size: file.size,
    };
    return { success: true as const, data };
  } catch (error) {
    console.error("Cloudinary chat upload error:", error);
    return { error: "Errore durante il caricamento del file" };
  }
}
```

```ts
import { auth } from "@/auth";
import { loadConversation } from "@/lib/chat/access";
import { parseChannel } from "@/lib/chat/channels";
import { getPusher } from "@/lib/pusher/server";

/**
 * pusher-js asks here before joining a private channel. A user channel is yours alone;
 * a match channel needs the same access as the chat itself.
 */
export async function POST(request: Request) {
  const pusher = getPusher();
  if (!pusher) return new Response("Realtime non configurato", { status: 503 });

  const session = await auth();
  const userId = session?.user?.id;
  if (!userId) return new Response("Non autorizzato", { status: 401 });

  const form = await request.formData().catch(() => null);
  const socketId = form?.get("socket_id");
  const channelName = form?.get("channel_name");
  if (typeof socketId !== "string" || typeof channelName !== "string") {
    return new Response("Richiesta non valida", { status: 400 });
  }

  const channel = parseChannel(channelName);
  const allowed =
    channel?.kind === "user"
      ? channel.id === userId
      : channel?.kind === "match"
        ? !("error" in (await loadConversation(channel.id, userId)))
        : false;
  if (!allowed) return new Response("Non autorizzato", { status: 403 });

  try {
    return Response.json(pusher.authorizeChannel(socketId, channelName));
  } catch {
    // authorizeChannel throws on a malformed socket id
    return new Response("Richiesta non valida", { status: 400 });
  }
}
```

```ts
// most recent activity (last message, else the match itself) comes first.
async function withChatPreviews<T extends { id: string; matchedAt: Date | null; lastMessageAt: Date | null; blockedById: string | null }>(
  userId: string,
  list: T[]
) {
  const previews = await loadChatPreviews(userId, list.map((m) => m.id));
  const activity = (m: T) => (m.lastMessageAt ?? m.matchedAt)?.getTime() ?? 0;
  return [...list]
    .sort((a, b) => activity(b) - activity(a))
    .map((m) => {
      const { lastMessageAt, blockedById, ...row } = m;
      const chat: ChatSummary = {
        ...(previews.get(m.id) ?? { lastMessage: null, unread: 0 }),
        lastMessageAt: lastMessageAt?.toISOString() ?? null,
        blocked: blockedById !== null,
      };
      return { ...row, chat };
    });
}
```

```ts
import type { ChatMessage, UploadedAttachment } from "./types";

export type OutgoingDraft = { body: string; file: File | null; uploaded?: UploadedAttachment };

export type ThreadMessage = ChatMessage & {
  /** Set on messages written in this tab: the render key, stable from optimistic to confirmed */
  clientId?: string;
  status: "sent" | "sending" | "failed";
  error?: string;
  /** What to resend on "Riprova" */
  draft?: OutgoingDraft;
};

const chronological = (a: ChatMessage, b: ChatMessage) =>
  a.createdAt === b.createdAt ? (a.id < b.id ? -1 : a.id > b.id ? 1 : 0) : a.createdAt < b.createdAt ? -1 : 1;

/**
 * One list from every source (server pages, Pusher events, catch-up fetches): server
 * messages deduped by id in chronological order, then the ones still being sent.
 */
export function mergeMessages(prev: ThreadMessage[], incoming: ChatMessage[]): ThreadMessage[] {
  const sent = new Map<string, ThreadMessage>();
  const pending: ThreadMessage[] = [];
  for (const m of prev) {
    if (m.status === "sent") sent.set(m.id, m);
    else pending.push(m);
  }
  for (const m of incoming) {
    sent.set(m.id, { ...m, status: "sent", clientId: sent.get(m.id)?.clientId });
  }
  return [...[...sent.values()].sort(chronological), ...pending];
}

/** The server accepted an optimistic message: swap it for the stored one. */
export function confirmPending(prev: ThreadMessage[], clientId: string, message: ChatMessage): ThreadMessage[] {
  const rest = prev.filter((m) => m.status === "sent" || m.clientId !== clientId);
  return mergeMessages(rest, [message]).map((m) => (m.id === message.id ? { ...m, clientId } : m));
}
```

```ts
  const date = new Date(iso);
  if (isSameDay(date, now)) return format(date, "HH:mm");
  if (isSameDay(date, new Date(now.getFullYear(), now.getMonth(), now.getDate() - 1))) return "Ieri";
  if (isSameYear(date, now)) return format(date, "d MMM", { locale: it });
  return format(date, "dd/MM/yy");
}

export function formatDayLabel(date: Date, now = new Date()) {
  if (isSameDay(date, now)) return "Oggi";
  if (isSameDay(date, new Date(now.getFullYear(), now.getMonth(), now.getDate() - 1))) return "Ieri";
  return format(date, isSameYear(date, now) ? "EEEE d MMMM" : "EEEE d MMMM yyyy", { locale: it });
}
```

```tsx
"use client";

import { createContext, useCallback, useContext, useEffect, useMemo, useRef, useState } from "react";
import { useSession } from "next-auth/react";
import { getUnreadTotal } from "@/app/actions/chat";
import { CHAT_EVENTS, userChannel } from "@/lib/chat/channels";
import { getPusherClient } from "@/lib/pusher/client";

type InboxListener = (matchId: string | null) => void;

interface ChatRealtime {
  unreadTotal: number;
  refreshUnread: () => void;
  /** Called when any of your conversations changes; matchId is null after a fallback poll */
  onInboxUpdate: (listener: InboxListener) => () => void;
}

const ChatRealtimeContext = createContext<ChatRealtime>({
  unreadTotal: 0,
  refreshUnread: () => {},
  onInboxUpdate: () => () => {},
});

const FALLBACK_POLL_MS = 60_000;

/** One subscription to your user channel for the whole app: nav badges and the inbox. */
export function ChatRealtimeProvider({ children }: { children: React.ReactNode }) {
  const { data: session } = useSession();
  const userId = session?.user?.id;
  const [unreadTotal, setUnreadTotal] = useState(0);
  const listeners = useRef(new Set<InboxListener>());
  const latestRequest = useRef(0);
  const lastTotal = useRef(0);

  // Resolves to whether the total changed; out-of-order answers are dropped
  const fetchUnread = useCallback(async () => {
    const request = ++latestRequest.current;
    const res = await getUnreadTotal().catch(() => null);
    if (!res || "error" in res || request !== latestRequest.current) return false;
    const changed = res.data !== lastTotal.current;
    lastTotal.current = res.data;
    setUnreadTotal(res.data);
    return changed;
  }, []);

  useEffect(() => {
    if (!userId) return;
    void fetchUnread();
    const notify = (matchId: string | null) => listeners.current.forEach((listener) => listener(matchId));

    const pusher = getPusherClient();
    const name = userChannel(userId);
    const channel = pusher?.subscribe(name);
    const onInbox = ({ matchId }: { matchId: string }) => {
      void fetchUnread();
      notify(matchId);
    };
    channel?.bind(CHAT_EVENTS.inbox, onInbox);

    // Without realtime the badge (and an open inbox) still catch up, just more slowly
    const poll = window.setInterval(async () => {
      if (document.visibilityState === "visible" && (await fetchUnread())) notify(null);
    }, FALLBACK_POLL_MS);

    return () => {
      window.clearInterval(poll);
      channel?.unbind(CHAT_EVENTS.inbox, onInbox);
      pusher?.unsubscribe(name);
    };
  }, [userId, fetchUnread]);

  const refreshUnread = useCallback(() => void fetchUnread(), [fetchUnread]);
  const onInboxUpdate = useCallback((listener: InboxListener) => {
    listeners.current.add(listener);
    return () => {
      listeners.current.delete(listener);
    };
  }, []);

  const value = useMemo(() => ({ unreadTotal, refreshUnread, onInboxUpdate }), [unreadTotal, refreshUnread, onInboxUpdate]);
  return <ChatRealtimeContext.Provider value={value}>{children}</ChatRealtimeContext.Provider>;
}

export const useChatRealtime = () => useContext(ChatRealtimeContext);
```

```ts
"use client";

import { useCallback, useEffect, useRef, useState } from "react";
import type { Channel } from "pusher-js";
import { getMessages, markRead, sendMessage, uploadChatAttachment } from "@/app/actions/chat";
import { CHAT_EVENTS, matchChannel } from "@/lib/chat/channels";
import { confirmPending, mergeMessages, type OutgoingDraft, type ThreadMessage } from "@/lib/chat/merge";
import type { ChatMessage, ThreadPage } from "@/lib/chat/types";
import { currentSocketId, getPusherClient } from "@/lib/pusher/client";

export type { OutgoingDraft, ThreadMessage };

const POLL_MS = 10_000;
const TYPING_THROTTLE_MS = 3_000;
const TYPING_TTL_MS = 5_000;
const OFFLINE = "Connessione assente. Riprova.";

interface Options {
  matchId: string;
  viewerId: string;
  initial: ThreadPage;
  /** The thread is on screen (not behind the "Dettagli" tab) */
  visible: boolean;
}

/**
 * State of one conversation: server pages, Pusher events, optimistic sends and the
 * polling fallback, merged into one list. The DB stays the source of truth: any doubt
 * (reconnect, tab back in view, failed send) is resolved by fetching what's newer.
 */
export function useChatThread({ matchId, viewerId, initial, visible }: Options) {
  const [messages, setMessages] = useState<ThreadMessage[]>(() => mergeMessages([], initial.messages));
  const [hasMore, setHasMore] = useState(initial.hasMore);
  const [loadingOlder, setLoadingOlder] = useState(false);
  const [otherLastReadAt, setOtherLastReadAt] = useState(initial.otherLastReadAt);
  const [blockedById, setBlockedById] = useState(initial.blockedById);
  const [otherTyping, setOtherTyping] = useState(false);
  const [live, setLive] = useState(false);

  const messagesRef = useRef(messages);
  const visibleRef = useRef(visible);
  const channelRef = useRef<Channel | null>(null);
  const typingTimer = useRef<number | undefined>(undefined);
  const readTimer = useRef<number | undefined>(undefined);
  const lastTypingSent = useRef(0);

  useEffect(() => {
    messagesRef.current = messages;
  }, [messages]);
  useEffect(() => {
    visibleRef.current = visible;
  }, [visible]);

  // Debounced: a burst of incoming messages costs one write
  const scheduleRead = useCallback(() => {
    if (!visibleRef.current || document.visibilityState !== "visible") return;
    window.clearTimeout(readTimer.current);
    readTimer.current = window.setTimeout(() => {
      void markRead(matchId, currentSocketId()).catch(() => {});
    }, 300);
  }, [matchId]);

  const catchUp = useCallback(async () => {
    const after = messagesRef.current.findLast((m) => m.status === "sent")?.id;
    const res = await getMessages(matchId, after ? { after } : {}).catch(() => null);
    if (!res || "error" in res) return;
    const { messages: fresh } = res.data;
    if (fresh.length > 0) setMessages((prev) => mergeMessages(prev, fresh));
    setOtherLastReadAt(res.data.otherLastReadAt);
    setBlockedById(res.data.blockedById);
    if (fresh.some((m) => m.senderId !== viewerId)) scheduleRead();
  }, [matchId, viewerId, scheduleRead]);

  // Realtime
  useEffect(() => {
    const pusher = getPusherClient();
    if (!pusher) return;
    const name = matchChannel(matchId);
    const channel = pusher.subscribe(name);
    channelRef.current = channel;

    // Anything sent between the server render and now (or while disconnected) is fetched
    channel.bind("pusher:subscription_succeeded", () => {
      setLive(true);
      void catchUp();
    });
    channel.bind("pusher:subscription_error", () => setLive(false));
    channel.bind(CHAT_EVENTS.newMessage, (message: ChatMessage) => {
      setMessages((prev) => mergeMessages(prev, [message]));
      if (message.senderId !== viewerId) {
        setOtherTyping(false);
        scheduleRead();
      }
    });
    channel.bind(CHAT_EVENTS.read, (e: { userId: string; readAt: string }) => {
      if (e.userId !== viewerId) setOtherLastReadAt(e.readAt);
    });
    channel.bind(CHAT_EVENTS.blocked, (e: { blockedById: string }) => setBlockedById(e.blockedById));
    channel.bind(CHAT_EVENTS.unblocked, () => setBlockedById(null));
    channel.bind(CHAT_EVENTS.typing, (e: { userId: string }) => {
      if (e.userId === viewerId) return;
      setOtherTyping(true);
      window.clearTimeout(typingTimer.current);
      typingTimer.current = window.setTimeout(() => setOtherTyping(false), TYPING_TTL_MS);
    });

    const onState = ({ current }: { current: string }) => {
      setLive(current === "connected" && channel.subscribed);
      if (current === "connected") void catchUp();
    };
    pusher.connection.bind("state_change", onState);

    return () => {
      pusher.connection.unbind("state_change", onState);
      channel.unbind_all();
      pusher.unsubscribe(name);
      channelRef.current = null;
      window.clearTimeout(typingTimer.current);
    };
  }, [matchId, viewerId, catchUp, scheduleRead]);

  // Polling fallback while realtime is unavailable
  useEffect(() => {
    if (live) return;
    const timer = window.setInterval(() => {
      if (document.visibilityState === "visible") void catchUp();
    }, POLL_MS);
    return () => window.clearInterval(timer);
  }, [live, catchUp]);

  // Back to the tab: catch up and read
  useEffect(() => {
    const onVisibility = () => {
      if (document.visibilityState !== "visible") return;
      void catchUp();
      scheduleRead();
    };
    document.addEventListener("visibilitychange", onVisibility);
    return () => document.removeEventListener("visibilitychange", onVisibility);
  }, [catchUp, scheduleRead]);

  // Opening the thread (or switching to the Chat tab) reads it
  useEffect(() => {
    if (visible) scheduleRead();
  }, [visible, scheduleRead]);

  useEffect(() => () => window.clearTimeout(readTimer.current), []);

  const fail = useCallback((clientId: string, error: string) => {
    setMessages((prev) =>
      prev.map((m): ThreadMessage => (m.clientId === clientId && m.status !== "sent" ? { ...m, status: "failed", error } : m))
    );
  }, []);

  const deliver = useCallback(
    async (clientId: string, draft: OutgoingDraft) => {
      let attachment = draft.uploaded;
      if (draft.file && !attachment) {
        const form = new FormData();
        form.append("file", draft.file);
        const upload = await uploadChatAttachment(matchId, form).catch(() => ({ error: OFFLINE }));
        if ("error" in upload) return fail(clientId, upload.error);
        attachment = upload.data;
        const uploaded = attachment;
        // "Riprova" reuses the upload
        setMessages((prev) => prev.map((m) => (m.clientId === clientId ? { ...m, draft: { ...draft, uploaded } } : m)));
      }
      const res = await sendMessage(matchId, { clientId, body: draft.body, attachment, socketId: currentSocketId() }).catch(
        () => ({ error: OFFLINE })
      );
      if ("error" in res) {
        fail(clientId, res.error);
        // e.g. the conversation was just closed: pick up the new state
        void catchUp();
        return;
      }
      setMessages((prev) => confirmPending(prev, clientId, res.data.message));
    },
    [matchId, fail, catchUp]
  );

  const send = useCallback(
    (draft: OutgoingDraft) => {
      const clientId = crypto.randomUUID();
      const optimistic: ThreadMessage = {
        id: clientId,
        clientId,
        matchId,
        senderId: viewerId,
        body: draft.body.trim() || null,
        attachment: draft.file ? { url: "", name: draft.file.name, mime: draft.file.type, size: draft.file.size } : null,
        createdAt: new Date().toISOString(),
        status: "sending",
        draft,
      };
      setMessages((prev) => [...prev, optimistic]);
      void deliver(clientId, draft);
    },
    [matchId, viewerId, deliver]
  );

  const retry = useCallback(
    (clientId: string) => {
      const message = messagesRef.current.find((m) => m.clientId === clientId && m.status === "failed");
      if (!message?.draft) return;
      setMessages((prev) => prev.map((m): ThreadMessage => (m === message ? { ...m, status: "sending", error: undefined } : m)));
      void deliver(clientId, message.draft);
    },
    [deliver]
  );

  const discard = useCallback((clientId: string) => {
    setMessages((prev) => prev.filter((m) => m.status === "sent" || m.clientId !== clientId));
  }, []);

  const notifyTyping = useCallback(() => {
    const channel = channelRef.current;
    const now = Date.now();
    if (!channel?.subscribed || now - lastTypingSent.current < TYPING_THROTTLE_MS) return;
    lastTypingSent.current = now;
    channel.trigger(CHAT_EVENTS.typing, { userId: viewerId });
  }, [viewerId]);

  const loadOlder = useCallback(async () => {
    const oldest = messagesRef.current.find((m) => m.status === "sent")?.id;
    if (!oldest || loadingOlder) return 0;
    setLoadingOlder(true);
    const res = await getMessages(matchId, { before: oldest }).catch(() => null);
    setLoadingOlder(false);
    if (!res || "error" in res) return 0;
    setMessages((prev) => mergeMessages(prev, res.data.messages));
    setHasMore(res.data.hasMore);
    return res.data.messages.length;
  }, [matchId, loadingOlder]);

  return {
    messages, hasMore, loadingOlder, loadOlder,
    otherLastReadAt, blockedById, setBlockedById,
    otherTyping, live,
    send, retry, discard, notifyTyping,
  };
}
```

```tsx
  const [text, setText] = useState("");
  const [file, setFile] = useState<File | null>(null);
  const textRef = useRef<HTMLTextAreaElement>(null);
  const fileRef = useRef<HTMLInputElement>(null);
  const canSend = text.trim().length > 0 || file !== null;

  const resize = () => {
    const el = textRef.current;
    if (!el) return;
    el.style.height = "auto";
    el.style.height = `${Math.min(el.scrollHeight, 160)}px`;
  };

  const submit = (e?: FormEvent) => {
    e?.preventDefault();
    if (!canSend) return;
    onSend({ body: text, file });
    setText("");
    setFile(null);
    requestAnimationFrame(resize);
    textRef.current?.focus();
  };

  const onKeyDown = (e: KeyboardEvent<HTMLTextAreaElement>) => {
    // Enter sends, Shift+Enter is a new line; never while an IME is composing
    if (e.key === "Enter" && !e.shiftKey && !e.nativeEvent.isComposing) {
      e.preventDefault();
      submit();
    }
  };

  const pick = (picked: File | undefined) => {
    if (fileRef.current) fileRef.current.value = "";
    if (!picked) return;
    if (!(ATTACHMENT_MIME_TYPES as readonly string[]).includes(picked.type)) {
      toast.error("Formato non supportato. Invia un'immagine (JPG, PNG, WebP, GIF) o un PDF.");
      return;
    }
    if (picked.size > MAX_ATTACHMENT_BYTES) {
      toast.error("File troppo grande. Massimo 5MB.");
      return;
    }
    setFile(picked);
  };

  return (
    <form onSubmit={submit} className="shrink-0 border-t border-viola/15 bg-white px-3 py-3">
      {file && (
        <div className="mb-2 flex items-center gap-2 rounded-full bg-crema pl-4 pr-1 h-10 text-sm text-viola">
          <Paperclip size={16} aria-hidden="true" className="shrink-0" />
          <span className="truncate flex-1">{file.name}</span>
          <span className="text-label text-viola-500 shrink-0">{formatBytes(file.size)}</span>
          <button
            type="button"
            onClick={() => setFile(null)}
            aria-label="Rimuovi allegato"
            className="pressable size-8 rounded-full flex items-center justify-center hover:bg-white shrink-0"
          >
            <X size={16} />
          </button>
        </div>
      )}
      <div className="flex items-end gap-2">
        <input
          ref={fileRef}
          type="file"
          accept={ATTACHMENT_MIME_TYPES.join(",")}
          className="hidden"
          onChange={(e) => pick(e.target.files?.[0])}
        />
        <button
          type="button"
          onClick={() => fileRef.current?.click()}
          aria-label="Allega un file"
          className="pressable size-11 shrink-0 rounded-full flex items-center justify-center text-viola hover:bg-crema"
        >
          <Paperclip size={22} strokeWidth={1.75} />
        </button>
        <div className="flex-1 min-w-0 rounded-3xl bg-crema px-4 py-2.5 focus-within:ring-3 focus-within:ring-ring/50">
          <textarea
            ref={textRef}
            rows={1}
            value={text}
            maxLength={MAX_BODY_LENGTH}
            onChange={(e) => {
              setText(e.target.value);
              resize();
              onTyping();
            }}
            onKeyDown={onKeyDown}
            placeholder={`Scrivi a ${recipientName}…`}
            aria-label={`Scrivi a ${recipientName}`}
            enterKeyHint="send"
            className="block w-full resize-none bg-transparent text-body text-viola placeholder:text-viola-400 outline-none max-h-40"
          />
          {text.length > MAX_BODY_LENGTH - 200 && (
            <p className="text-right text-label text-viola-500 tabular-nums">{text.length}/{MAX_BODY_LENGTH}</p>
          )}
        </div>
        <button
          type="submit"
          disabled={!canSend}
          aria-label="Invia"
          className="pressable size-11 shrink-0 rounded-full bg-viola text-white flex items-center justify-center disabled:bg-viola/40 disabled:cursor-not-allowed"
        >
          <ArrowUp size={20} strokeWidth={2} />
        </button>
      </div>
    </form>
  );
}
```

```tsx
import { AnimatePresence, motion } from "framer-motion";
import { cn } from "@/lib/utils";
import { formatDayLabel, formatMessageTime } from "@/lib/chat/format";
import type { ThreadPage } from "@/lib/chat/types";
import { ChatAttachment } from "./ChatAttachment";

import { ChatMenu } from "./ChatMenu";

interface ChatThreadProps {
  matchId: string;
  viewerId: string;
  otherName: string;
  initial: ThreadPage;
}

const sameDay = (a: string, b: string) => new Date(a).toDateString() === new Date(b).toDateString();

export function ChatThread({ matchId, viewerId, otherName, initial }: ChatThreadProps) {
  const visible = useChatVisible();
  const thread = useChatThread({ matchId, viewerId, initial, visible });
  const listRef = useRef<HTMLDivElement>(null);
  const atBottom = useRef(true);
  const prependFrom = useRef<number | null>(null);

  const onScroll = () => {
    const el = listRef.current;
    if (el) atBottom.current = el.scrollHeight - el.scrollTop - el.clientHeight < 120;
  };

  // New messages scroll the reader down only if they were already at the bottom (or wrote
  // it); older pages keep the reader where they were.
  useLayoutEffect(() => {
    const el = listRef.current;
    if (!el) return;
    if (prependFrom.current !== null) {
      el.scrollTop = el.scrollHeight - prependFrom.current;
      prependFrom.current = null;
      return;
    }
    if (atBottom.current || thread.messages.at(-1)?.senderId === viewerId) el.scrollTop = el.scrollHeight;
  }, [thread.messages, viewerId]);

  // A hidden thread has no height: land at the bottom when it is shown
  useEffect(() => {
    const el = listRef.current;
    if (visible && el && atBottom.current) el.scrollTop = el.scrollHeight;
  }, [visible]);

  const loadOlder = async () => {
    const el = listRef.current;
    if (el) prependFrom.current = el.scrollHeight - el.scrollTop;
    const added = await thread.loadOlder();
    if (added === 0) prependFrom.current = null;
  };

  const lastOwnSent = thread.messages.findLast((m) => m.senderId === viewerId && m.status === "sent");
  const blocked = thread.blockedById !== null;

  return (
    <div className="flex h-full min-h-0 flex-col bg-white">
      <div className="flex h-14 shrink-0 items-center justify-between gap-3 border-b border-viola/15 pl-4 pr-2">
        <h2 className="truncate text-body font-bold text-viola">Chat con {otherName}</h2>
        <ChatMenu
          matchId={matchId}
          viewerId={viewerId}
          otherName={otherName}
          blockedById={thread.blockedById}
          onBlockedChange={thread.setBlockedById}
        />
      </div>

      <div
        ref={listRef}
        onScroll={onScroll}
        role="log"
        aria-label={`Messaggi con ${otherName}`}
        className="flex-1 min-h-0 overflow-y-auto overscroll-contain custom-scrollbar px-4 py-4"
      >
        {thread.hasMore && (
          <div className="flex justify-center pb-4">
            <button
              type="button"
              onClick={() => void loadOlder()}
              disabled={thread.loadingOlder}
              className="pressable h-9 rounded-full bg-crema px-4 text-label font-semibold text-viola disabled:opacity-60"
            >
              {thread.loadingOlder ? "Caricamento…" : "Carica messaggi precedenti"}
            </button>
          </div>
        )}

        {thread.messages.length === 0 ? (
          <div className="flex h-full flex-col items-center justify-center px-6 text-center">
            <p className="text-body font-bold text-viola">Rompi il ghiaccio.</p>
            <p className="mt-1 text-sm text-viola-500">Scrivi a {otherName}: è il primo messaggio della vostra chat.</p>
          </div>
        ) : (
          <ol className="flex flex-col gap-1.5">
            <AnimatePresence initial={false}>
              {thread.messages.map((m, i) => {
                const previous = thread.messages[i - 1];
                return (
                  <Fragment key={m.clientId ?? m.id}>
                    {(!previous || !sameDay(previous.createdAt, m.createdAt)) && (
                      <li className="self-center py-2 text-label font-semibold text-viola-500 first-letter:uppercase">
                        {formatDayLabel(new Date(m.createdAt))}
                      </li>
                    )}
                    <MessageBubble
                      message={m}
                      mine={m.senderId === viewerId}
                      receipt={
                        m === lastOwnSent
                          ? thread.otherLastReadAt && thread.otherLastReadAt >= m.createdAt
                            ? "Letto"
                            : "Inviato"
                          : null
                      }
                      onRetry={() => thread.retry(m.clientId!)}
                      onDiscard={() => thread.discard(m.clientId!)}
                    />
                  </Fragment>
                );
              })}
            </AnimatePresence>
          </ol>
        )}
      </div>

      <p aria-live="polite" className="h-5 shrink-0 px-4 text-label text-viola-500">
        {thread.otherTyping && !blocked ? `${otherName} sta scrivendo…` : ""}
      </p>

      {blocked ? (
        <div className="shrink-0 border-t border-viola/15 bg-crema px-4 py-4 text-center text-sm text-viola">
          <p className="font-bold">Conversazione chiusa</p>
          <p className="text-viola-500">
            {thread.blockedById === viewerId
              ? "L'hai bloccata tu: puoi sbloccarla dal menu ⋯."
              : "Non è più possibile scrivere in questa chat."}
          </p>
        </div>
      ) : (
        <ChatComposer recipientName={otherName} onSend={thread.send} onTyping={thread.notifyTyping} />
      )}
    </div>
  );
```
